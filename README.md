## 📋 Overview

This is my personal portfolio website showcasing my skills, projects, internship experience, and education. It's designed to serve as a professional landing page for recruiters, collaborators, and anyone who wants to know more about my work.

**Live at:** `https://<your-github-username>.github.io/monish-portfolio`

---

## ✨ Features

- **Single-file architecture** — everything lives in one `monish_portfolio.html` file; no build step required
- **Responsive design** — works seamlessly across desktop, tablet, and mobile
- **Smooth scroll navigation** — fixed navbar with anchor-based section jumping
- **Scroll-triggered animations** — fade-in effects powered by the Intersection Observer API
- **Dark navy hero** with animated radial gradient accent
- **Projects section** with tech stack tags and key highlights per project
- **Timeline-based experience** layout
- **Zero dependencies** — only Google Fonts loaded via CDN

## 🚀 Getting Started

No setup needed. Just clone and open:

```bash
git clone https://github.com/<your-username>/monish-portfolio.git
cd monish-portfolio
open monish_portfolio.html
```

Or drag the file into any browser.

---

## 🌍 Deploying to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)`
4. Visit `https://<your-username>.github.io/monish-portfolio/monish_portfolio.html`
